# Changelog

## 0.3.0

- Add `:<number><Enter>` to jump to a physical PDF page, with a visible prompt,
  Backspace editing, and Escape cancellation.

## 0.2.1

- Fix cancelled tooltips permanently blocking library and PDF keys.
- Check current menu state so dismissed menus cannot leave navigation blocked.
- Handle PDF keys when Zotero focuses the reader's outer window.

## 0.2.0

- Add PDF scrolling, page jumps, search, zoom, and tab navigation.
- Support split panes, separate reader windows, and papers already open when
  the plugin is enabled.

## 0.1.0

- Add library navigation, counts, extended selection, row expansion, pane
  switching, search, attachment opening, and tab navigation.
- Add shortcut help and a persistent navigation toggle.
